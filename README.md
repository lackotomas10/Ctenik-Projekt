# 📚 Čteník

**Každá stránka se počítá.** Čteník je čtenářský deník, který vám pomůže zaznamenávat čas s knihou, sledovat vlastní pokrok a motivovat se v přátelském žebříčku.

[Otevřít Čteník](https://ctenik.netlify.app/) · [Soutěž](Sout%C4%9B%C5%BE.html)

## Co můžete dělat

- Zapisovat přečtené minuty a dokončené knihy.
- Sledovat statistiky, čtecí řadu a týdenní graf.
- Přihlásit se, vytvořit účet a spravovat svá data.
- Porovnat výsledky v žebříčku; účast v soutěži lze vypnout v nastavení.

## Cíl projektu
Čteník chce studenty motivovat ke čtení, pomáhat jim sledovat pokrok a spojovat je v přátelské soutěži.
